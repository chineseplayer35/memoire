# 成本估算与可观测

## 为什么便宜

这套系统的成本只有两类：

1. **每日定时提炼**（22:30 + 4h 空闲前）：每个活跃会话/人每天 1~2 次模型调用，**没有新消息就完全不调用**。
2. **主动记录**：模型偶尔主动写日记/更新印象卡（一次小调用）。

没有第三条路：没有每条消息的检索、重排、导航、总结。

## 粗略估算（DeepSeek 价格，群聊 100~300 条/天）

| 项 | 频率 | 成本 |
|---|---|---|
| 每日事记+印象提炼 | 每活跃会话/人 1 次 | 几分~一毛/天 |
| 主动记录 | 一天几次 | 可忽略 |
| 注入多吃的 token（7 条事记 + 印象卡 + 日记） | 每条回复多几百~一千 token，大多缓存命中 | 几分钱/天 |
| **合计** | | **约 0.05~0.3 元/天** |

对比"每条消息都有模型调用"的重型记忆插件（常见为每天几块~十几块），**长期成本约为其 1/20 ~ 1/50**。

## 可观测

- `usage.jsonl`：每次后台调用的用途、provider、输入/输出 token、耗时、状态。
- `provider_stats`：后台调用写入统一统计，方便控制台/成本插件读取。
- 游标与指纹：每次提炼的位置和结果都可复查，失败会重试，不会悄悄丢记忆。
